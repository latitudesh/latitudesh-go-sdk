# Permission

`readonly` grants read-only access; `rw` grants read and write access.

## Example Usage

```go
import (
	"github.com/latitudesh/latitudesh-go-sdk/models/operations"
)

value := operations.PermissionReadonly
```

| `PermissionReadonly` | readonly             |
